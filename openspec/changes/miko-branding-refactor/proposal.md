## Why

Make the existing application easier to maintain and identify as Miko Finance while preserving financial behavior.

## What Changes

- Introduce a spec-driven record of the current change and behavioral invariants.
- Improve readability of navigation and merchant classification without changing their outcomes.
- Replace launcher artwork with a simplified illustration derived from the provided reference and update display names.

## Capabilities

### New Capabilities
- `app-identity`: Launcher identity and display name.
- `existing-behavior`: Record existing navigation, transaction data and merchant classification invariants.

### Modified Capabilities
- None; this repository has no prior baseline specifications.

## Impact

Flutter navigation, classification service, platform display names and launcher image assets. No database schema or application identifier changes.
